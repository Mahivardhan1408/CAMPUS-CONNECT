
# CampusConnect – Your Smart College Companion

## About the Project

CampusConnect is a web-based college companion designed to help students access useful campus information in one place. It provides a simple interface for browsing announcements, exploring college events, reporting lost and found items, and viewing student marketplace listings.

## Objectives

- Provide a central place for college announcements.
- Help students report lost and found items.
- Display information about college events.
- Organize marketplace listings by category.
- Make campus information easier to access.

## Features

### 1. Dashboard
A home page with navigation cards for accessing the main sections.

### 2. Announcements
Students can search sample college notices using keywords.

### 3. Lost & Found
Users can submit an item name, report type, and location. Reports are saved locally in the browser.

### 4. College Events
Displays example technical, cultural, and project-related activities.

### 5. Student Marketplace
Displays sample listings for books, electronics, and stationery. Users can filter listings by category and search by keyword.

## Limitations

- Announcements, events, and marketplace listings are sample data.
- Lost & Found reports are stored only in the visitor's browser.
- The project does not currently include user accounts, shared databases, payments, or a connected AI summarization service.

## Future Enhancements

- Add student login and authentication.
- Connect a shared database.
- Allow authorized users to publish announcements.
- Add an AI-powered notice summarizer using a secure backend.
- Enable marketplace listing submissions.
- Add event registration and notifications.
